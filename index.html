About

What this demo shows and how it stays in sync with your repo.

This is a demonstration website showcasing automated deployment to GitHub Pages using GitHub Actions.

Every push to the main branch deploys automatically. The Try it button does the same thing, but only after you enter the demo password — credentials and GitHub tokens never live in this public page.

A private Cloudflare Worker verifies the password, enforces rate limits (once every 5 minutes, up to 5 times per UTC day per IP), and triggers GitHub Actions. The header shows the new deploy date and time when Pages finishes publishing.
